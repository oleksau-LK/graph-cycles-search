# Поиск всех циклов в графе

Решение задания 24 на Python 3 без внешних зависимостей.

`find_all_cycles(graph)` возвращает список всех простых циклов неориентированного графа, включая циклы в разных компонентах связности. Цикл содержит не менее трёх вершин; начальная вершина в конце не повторяется. Сдвиги и обратные направления одного цикла исключены.

Граф задаётся словарём списков соседей. Все вершины, включая изолированные, должны быть ключами. Каждое ребро указывается в обе стороны, без повторов и петель. Метки вершин могут быть любыми хешируемыми объектами. Входной граф не изменяется.

```python
from cycles import find_all_cycles

graph = {0: [1, 2], 1: [0, 2], 2: [0, 1], 3: []}
print(find_all_cycles(graph))
```

Результат: `[[0, 1, 2]]`.

Рекурсивный DFS отслеживает путь и посещённые в нём вершины. Цикл сохраняется только из вершины с наименьшим индексом в порядке ключей словаря и только в одном направлении. Глубина рекурсии ограничена настройками Python. Число циклов может расти факториально; все найденные циклы хранятся в памяти.

Запуск тестов:

```sh
python3 -m unittest -v
```

Тесты проверяют графы без циклов, один цикл, пересекающиеся циклы, несвязность, разные типы меток, повторные вызовы и сохранность входных данных. Полнота и отсутствие дубликатов дополнительно проверяются независимым перебором для всех 1024 простых графов на пяти вершинах.
